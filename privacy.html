Privacy Policy

VPS Backup rclone

Last updated: October 16, 2026

1. Purpose

VPS Backup rclone is a privately operated backup utility used to store and restore encrypted VPS backups using Google Drive, rclone and Restic. It is not offered as a public service.

2. Google Drive Access

The application uses Google OAuth 2.0 to access the account owner's Google Drive. Depending on the permissions granted, the application may have access to other files within the authorized Google Drive account. Its intended use is limited to managing the designated backup repository.

3. Data Processing

Server backup contents are encrypted locally using Restic before upload to Google Drive. The application transfers, reads and manages backup repository data as required for backup and restoration operations.

4. Authentication Data

OAuth credentials and access tokens are stored in the private VPS environment for the purpose of maintaining authorized Google Drive access. They are not published on this website.

5. Data Sharing

The application does not sell personal data, use Google Drive data for advertising, or disclose Google Drive data to unrelated third parties. Google Drive provides the storage service under the account owner's Google service terms.

6. Data Retention and Deletion

Encrypted backups remain in the designated Google Drive repository until removed by the account owner or by configured backup retention policies. The account owner can delete backups and revoke application access through Google Account security settings.

7. Website Privacy

This informational website does not itself request access to Google Drive, collect Google account credentials, or operate its own analytics or advertising trackers. It is hosted using GitHub Pages, which may process technical access information under GitHub's own privacy practices.

8. Contact

For questions about this application or its privacy practices, contact the project owner through the GitHub repository.
