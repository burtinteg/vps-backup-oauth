VPS Backup rclone

VPS Backup rclone is a private backup utility used to securely store and restore encrypted backups of a privately managed VPS server.

How it works

The application uses rclone and the Google Drive API to transfer encrypted backups created with Restic to the account owner's Google Drive.

The application is intended for internal use by its owner and is not offered as a public backup service.

Data protection

Backup contents are encrypted before being uploaded to Google Drive. This website does not contain backup data or authentication credentials.
